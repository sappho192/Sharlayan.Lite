# Sharlayan.Lite 9.1.3 release 준비

## 목적

공개 `Sharlayan.Lite 9.1.2` package가 source repository의 current-first Talk API 및
`net10.0` target보다 앞선 commit에서 생성된 계약 문제를 해결한다. `9.1.2`를 재사용하지
않고 새 stable version `9.1.3`을 준비한다.

## 확인된 9.1.2 계약 차이

- 공개 9.1.2 package repository commit: `1f1bc330236a6cf4a0b3bd300eda3f8ca88f0aea`
- current Talk API 구현 commit: `3e27261f82851e1e88c413a25461e6ca0ad551e8`
- net10.0 지원 구현 commit: `4d38d25e5bb2c639f824b249589ddacb5b705fe3`
- 공개 DLL은 LastTalk API만 포함하고 current-first API와 `TalkResult.Source`,
  `TalkResult.IsVisible`을 포함하지 않는다.

## 9.1.3 package 계약

다음 API가 package의 public `net10.0` assembly에 존재하고 독립 PackageReference consumer가
compile 및 실행되어야 한다.

- `Reader.CanGetTalk()`
- `Reader.GetTalk()`
- `Reader.GetCurrentTalk()`
- `Reader.GetLastTalk()`
- `TalkResult.Source`
- `TalkResult.IsVisible`
- `TalkResult.IsAvailable`
- `TalkResult.Name`
- `TalkResult.Text`

Package verifier는 다음도 확인한다.

- repository commit metadata가 최종 verifier commit과 일치
- DLL informational version이 `9.1.3+<final-verifier-sha>`, file version이 `9.1.3.0`과 일치
- `net462`, `net48`, `net6.0`, `net7.0`, `net8.0`, `net10.0` DLL/PDB 포함
- package README 포함
- FCS, InteropGenerator, Lumina 및 불필요한 runtime assembly 부재
- 완전히 새로운 package cache 및 consumer directory에서 정확한 9.1.3 package restore
- restore된 nupkg byte SHA-256과 입력 artifact SHA-256 일치

2026-07-26 NuGet V3 index 확인 시 공개 version은 `8.0.1`, `9.1.2`이며 `9.1.3`은
존재하지 않았다.

## 자동 검증 명령

```powershell
dotnet run --project tools/Sharlayan.ChatResources.Generator/Sharlayan.ChatResources.Generator.csproj --configuration Release --no-launch-profile
git diff --exit-code -- Sharlayan/Resources/GeneratedChatResources.g.cs
dotnet restore Sharlayan.sln
dotnet build Sharlayan.sln --configuration Release --no-restore --nologo
dotnet test Sharlayan.Tests/Sharlayan.Tests.csproj --configuration Release --no-build --no-restore --nologo
dotnet pack Sharlayan/Sharlayan.csproj --configuration Release --no-build --no-restore --nologo --output artifacts/packages-9.1.3
.\tools\Verify-Package.ps1 -PackageDirectory .\artifacts\packages-9.1.3 -ExpectedPackageVersion 9.1.3 -ExpectedRepositoryCommit <final-verifier-sha>
.\tools\Verify-PackageConsumer.ps1 -PackageDirectory .\artifacts\packages-9.1.3 -ExpectedPackageVersion 9.1.3 -ExpectedRepositoryCommit <final-verifier-sha>
```

## 공개 전 필수 pending gate

9.1.2의 one-time waiver를 재사용하지 않는다. 다음 gate를 모두 실제 증거로 완료하기 전에는
NuGet publish와 외부 release 승격을 수행하지 않는다.

- 최종 package repository commit과 동일한 verifier SHA에서 current Talk, LastTalk fallback,
  CHATLOG polling live smoke
- 10분 이상 single-consumer polling
- 1,000 entry 또는 실제 wrap 전후 중복·누락 확인
- Say, Tell, Party, Alliance, Novice, System 명시적 channel fixture
- elevated process attach
- upstream Sharlayan 9.1.2와 동일 process 비교
- `release.yml`의 `publish=false` dry run 및 artifact 확인
- 수동 production 승인

이 문서는 자동 검증을 live gate의 대체 증거로 사용하지 않는다.
